Arti istilah teknis dan kata-kata berbahasa Inggris yang sering muncul di CMS.

## Istilah umum

| Istilah | Arti |
|---|---|
| **CMS** | *Content Management System*, yaitu aplikasi untuk mengelola isi website tanpa perlu menulis kode program |
| **Website / Landing page** | Situs publik BPI yang dilihat pengunjung |
| **Admin Panel** | Sebutan lain untuk CMS ini |
| **Role** | Peran atau hak akses akun: Super Admin, Admin, atau Editor |
| **Sidebar** | Menu di sisi kiri layar CMS |
| **Dashboard** | Halaman ringkasan yang tampil pertama kali setelah login |
| **Section** | Bagian dari sebuah halaman, misalnya bagian "Mitra Kami" di halaman depan |
| **Banner** | Gambar besar beserta judul di bagian atas halaman |
| **Badge** | Label kecil, biasanya di atas judul atau berupa kotak warna kecil |
| **Footer** | Bagian paling bawah website |
| **Default** | Pengaturan bawaan atau utama |
| **Slug** | Kode singkat tanpa spasi (huruf kecil dan tanda hubung) yang dipakai di alamat web, misalnya `festival-film` |
| **URL / Link** | Alamat web, misalnya `https://bpi.or.id/news` |
| **Shortlink** | Alamat web pendek yang mengarah ke alamat lain yang lebih panjang |
| **QR Code** | Kode kotak-kotak yang bisa dipindai kamera HP untuk membuka alamat web |
| **Upload / Unggah** | Mengirim file dari komputer Anda ke CMS |
| **WebP** | Format gambar modern berukuran kecil yang dipakai website agar cepat dibuka |
| **Font Awesome** | Kumpulan ikon yang dipakai website (kodenya seperti `fa-solid fa-film`) |
| **Rich Text Editor** | Kotak isian teks dengan tombol format seperti di Word |
| **Login / Logout** | Masuk / keluar dari CMS |
| **Remember Me** | Ingat saya: tetap masuk walaupun browser ditutup. Jangan dicentang di komputer bersama. |
| **Session / Sesi** | Masa login. Sesi berakhir otomatis jika lama tidak dipakai. |
