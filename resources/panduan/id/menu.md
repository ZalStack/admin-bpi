Menu **Menu** mengatur **menu navigasi** di bagian atas website, yaitu deretan tautan seperti *Beranda*, *Tentang Kami*, *Proyek*, *Berita*, dan *Kontak*.

Buka menu: [Menu](cms:admin.menu.index)

## Halaman daftar menu

| Kolom | Keterangan |
|---|---|
| **Name** | Nama menu yang tampil di website (bahasa default) |
| **Slug** | Kode unik yang dibuat otomatis. Bisa diabaikan. |
| **Url** | Alamat tujuan saat menu diklik |
| **Order** | Urutan dari kiri ke kanan (angka kecil di paling kiri) |
| **Status** | Active = tampil, Inactive = disembunyikan |

## Menambah menu

1. Klik **Add Menu**.
2. Pada **Select Website Page**, pilih halaman tujuan:
   - 🏠 **Home** ( / )
   - 👥 **Stakeholders** ( /stakeholders )
   - 🎬 **Projects** ( /project )
   - 📰 **Articles & News** ( /news )
   - 🏛️ **About Us** ( /about )
   - 📞 **Contact Us** ( /contact )
   - 🔒 **Privacy Policy** ( /privacy-policy )
   - 📜 **Terms & Conditions** ( /terms-conditions )
   - 🔗 **Custom Link / External URL…**: untuk alamat lain
3. Jika memilih halaman website, kolom **URL Link Data** terisi dan terkunci otomatis. Jika memilih **Custom Link**, isi sendiri alamatnya:
   - Halaman di website BPI: awali dengan garis miring, misalnya `/news`.
   - Website lain: tulis alamat lengkap, misalnya `https://festivalfilm.id`.
4. Isi **Display Order** dan centang **Status: Active**.
5. Isi **Menu Name** di tab **ID** (misalnya *Berita*) dan tab **EN** (misalnya *News*).
6. Klik **Save**.

## Mengubah urutan atau menyembunyikan menu

- **Urutan:** klik ✏️, ubah **Display Order**, lalu klik **Update**.
- **Menyembunyikan:** klik label **Active** sampai berubah menjadi **Inactive**.

> **Tips:** Batasi jumlah menu, sebaiknya 5–7 menu, agar navigasi tetap rapi, terutama di layar HP. Gunakan nama menu yang singkat (1–2 kata).

> **Perhatian:** Pastikan alamat **Custom Link** benar. Menu yang mengarah ke alamat salah akan membuat pengunjung melihat halaman "tidak ditemukan". Setelah menyimpan, klik menu tersebut di website untuk mengujinya.
