The **Projects** menu manages BPI's **collaborative projects**. Each project has a summary card on the **Projects** page and its own **detail** page with objectives, achievements, activities, a timeline, the partners involved, and a photo gallery.

Open menu: [Projects](cms:admin.proyek.index)

## The project list page

| Column / Button | Description |
|---|---|
| **Title** | Project title |
| **Image** | Cover image |
| **Status** | **Published** (shown) or **Draft** (not shown). Click to change. |
| Gallery icon (four small gold squares) | Opens the project's **photo gallery** |
| ✏️ / 🗑️ | Edit / Delete |

## Adding a project

The **Add Project** form is quite long and has three parts. Prepare the material first (texts in both languages and a cover image) so filling it in goes smoothly.

### Part 1: Year, Status & Main Image

- **Year / Period** (required): the project period, for example `2024 - Present`.
- **Publication Status**: choose **Draft** while you are still preparing the content, then **Published** when it is ready. The default is **Published**, so switch to **Draft** first if the project is not ready to be published.
- **Display Order**: the project's order on the Projects page.
- **Main Image / Project Cover**: the cover image (landscape, maximum 2 MB).

### Part 2: Partners / Collaborators

Tick the partners involved in this project. The list comes from the [Partners](bab:mitra) menu, and only **Active** partners appear. If a partner is missing, add it in the Partners menu first.

### Part 3: Multilingual Content Details

Fill in the **ID** tab, then repeat in the **EN** tab:

| Field | Required | Example / Description |
|---|---|---|
| **Project Title** | Yes | *BPI Film Market* |
| **Short Description** | Yes | 1–2 sentences for the project card |
| **Full Project Description** | Yes | The full explanation of the project |
| **Location** | Yes | *Jakarta, Indonesia* |
| **Scope** | No | *National & International* |
| **Project Status** | No | The project's condition, for example *Ongoing* or *Completed*. This is only text and does not affect whether the project is shown. |
| **Project Icon** | No | Click **Select** to choose an icon |
| **Brief Timeline** | Yes | *2022 - Present* |

Below these are four lists, each of which can have several rows:

| List | Each row contains | Add button |
|---|---|---|
| 🎯 **Project Objectives** | Icon + objective description | **+ Add Objective** |
| 📊 **Impact & Achievements** | Icon + a figure (for example *1,250+*) + its description (for example *Participants*) | **+ Add Achievement** |
| ⚡ **Main Activities** | Icon + activity description | **+ Add Activity** |
| 📅 **Timeline / Project Stages** | Year + stage description | **+ Add Timeline Entry** |

Click the 🗑️ icon at the end of a row to remove it. Empty rows are ignored automatically.

> **Important:** The four lists are filled in **separately for each language**. After filling in the objectives, achievements, activities, and timeline in the **ID** tab, go to the **EN** tab and fill in the same lists in English. If a list in the EN tab is left empty, the whole list from the ID tab is copied into it.

Finally, click **Save Project**.

## Changing a project

1. Click ✏️ on the project.
2. Change what you need, including the ticked partners and the list rows.
3. Click **Update Project**.

## Project photo gallery

The gallery holds documentation photos shown on the project detail page.

1. On the project list page, click the **gallery icon** (four small gold squares) on the project. The **Project Gallery** page opens.
2. Click **Add Gallery**.
3. Choose an **Image** (required; JPG, PNG, GIF, or WEBP, maximum 2 MB).
4. (Optional) Fill in the photo's **Title** and **Description** in each language tab.
5. Fill in **Order** and tick **Status: Active**.
6. Click **Save**. Repeat steps 2–6 for each photo.

To change or delete a photo, use the ✏️ / 🗑️ icon on the photo in the gallery page. Click **Back** to return to the project list.

> **Warning:** Deleting a **project** also permanently deletes **all of its gallery photos**. If a project is finished but you want to keep it, change its status to **Draft** or **Archived** instead.

## Texts on the Projects page

Section headings, statistics, tab names, the call to action "Memiliki Gagasan Proyek…", and the section headings on project detail pages (for example "TUJUAN PROYEK" and "GALERI FOTO") are changed with the **Page Texts** button. See the [Page Texts](bab:teks-halaman) chapter.
