The **Homepage** menu manages the **sections** shown on the website's home page: which sections appear and in what order from top to bottom.

Open menu: [Homepage](cms:admin.beranda.index)

## Which sections are on the home page?

| Section | What it shows | Its content is managed in |
|---|---|---|
| **About Us** (tentang) | A short BPI profile | [About](bab:tentang) |
| **Organizational Structure** (struktur) | A preview of the organizational structure | [Org. Structure](bab:struktur) |
| **Collaborative Projects** (proyek) | Collaborative projects | [Projects](bab:proyek) |
| **Strategic Programs** (program) | Strategic program pillars | [Programs](bab:program) |
| **Articles & News** (berita) | The latest news | [News](bab:berita) |
| **Partners** (mitra) | Partner logos | [Partners](bab:mitra) |

The banner at the very top of the home page is managed in the [Banner](bab:banner) menu (choose the **Home** page).

The picture below compares the section list in the CMS (left) with the website home page (right). The order of the sections on the website, from top to bottom, follows the **Display Order** column.

![Left: the section list in the Homepage menu with its order and status. Right: the website home page with the sections in that order](/images/panduan/beranda-cms-vs-website.webp)

So the Homepage menu is **not** used to change what each section contains. It only controls **whether** a section is shown and **in what order**.

## Hiding or showing a section

On the list page, click the **Active/Inactive** label in the **Display Status** column.

- **Active**: the section is shown on the home page.
- **Inactive**: the section is hidden from the home page.

## Changing the section order

1. Click the ✏️ icon (**Edit Order & Status**) on the section you want to move.
2. Change the **Display Order** number. Smaller numbers appear higher.
3. Click **Save Changes**.

> **Tip:** Number all sections in sequence, for example About Us = 1, Projects = 2, Programs = 3, and so on, so it is easy to read.

## Adding back a deleted section

Each type of section only needs to exist **once**. If a section was deleted by accident:

1. Click **Add Section**.
2. Choose the type of section in the **Section** field.
3. Fill in **Display Order**, then tick **Show on Homepage**.
4. Click **Save**.

> **Warning:** Do not add a section type that is already in the list, or that section may appear twice on the home page. If you only want to hide a section, use the **Inactive** status instead of deleting it.

## Changing headings and buttons on the home page

Section headings (for example "PROYEK KOLABORASI"), small labels, and button texts (for example "Lihat Semua Berita") are changed with the **Page Texts** button in the top right of this page. See the [Page Texts](bab:teks-halaman) chapter.
