Besides the main data (such as the list of news or partners), every website page has **built-in texts**: section headings, small labels (*badges*), button texts, and call-to-action sentences. All of these can be changed through the **Page Texts** feature.

## Where to find it

Page Texts does not have its own menu in the sidebar. Its button is at the top of the list page of the related menu:

| Texts for this website page | Open menu | Click the button |
|---|---|---|
| Home page | [Homepage](cms:admin.beranda.index) | **Page Texts** |
| Stakeholders page | [Stakeholder](cms:admin.stakeholder.index) or [Partners](cms:admin.mitra.index) | **Page Texts** / **Stakeholders Page Texts** |
| Projects page (including Programs & Roadmap, and the section headings of each project detail page) | [Projects](cms:admin.proyek.index) or [Programs](cms:admin.program.index) | **Page Texts** / **Projects Page Texts** |
| Organizational Structure section of the About page | [Org. Structure](cms:admin.struktur.index) or [About](cms:admin.tentang.index) | **Section Texts** / **Structure Section Texts** |
| Contact page | [Contact](cms:admin.kontak.index) | **Page Texts** |
| Footer (the very bottom of the website) | [Footer & Legal](cms:admin.footer.texts) | **Footer** tab |
| Privacy Policy page | [Footer & Legal](cms:admin.footer.texts) | **Privacy Policy** tab |
| Terms & Conditions page | [Footer & Legal](cms:admin.footer.texts) | **Terms & Conditions** tab |

## How to change a text

1. Open the Page Texts page you need (see the table above).
2. Texts are grouped by page section, for example **HERO BANNER** or **ABOUT US SECTION**. Each text has a description (for example **Title** or **"Button (links to About page)"**) and two fields: **ID · Bahasa Indonesia** on the left and **EN · English** on the right.
3. Change the text in the language field you want.
4. Click **Save Texts** at the bottom. The message *"Texts saved successfully"* appears.

Below is the **Homepage Texts** page as an example:

![The Homepage Texts page: texts grouped by page section, with Indonesian on the left, English on the right, and the Save Texts button at the bottom](/images/panduan/page-texts.webp)

> **Tip:** If a field is **left empty**, the website shows the **built-in text** prepared by the website developers. This is different from other menus, which copy the ID text into an empty EN field. So if you changed a text by mistake and want the original back, just empty the field and save.

## Good to know

- Some descriptions say **"(links to … page)"**. The button automatically leads to that page. You can only change its **text**, not where it leads.
- **"(count is added automatically)"** means the website adds the number itself (for example the number of partners or photos). Do not type a number in that text.
- **"(the year is added automatically)"** on the copyright text means the year is added automatically.
- **"(uses main email from Contact)"** means the button opens an email to the first email address listed in the **Contact** menu.
- Keep the existing writing style. For example, if the original text is in ALL CAPITALS, write yours in capitals too so it matches.
- Keep the text about as long as the original. Texts that are too long can make buttons or headings get cut off, especially on phones.
