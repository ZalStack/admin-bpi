The **Language Settings** menu manages the **languages available** on the website and in the CMS forms. Currently there are Indonesian (default) and English.

Open menu: [Language Settings](cms:admin.bahasa.index)

> **Warning:** Settings in this menu affect the **whole website**. For daily work you **do not need** to change anything here. Coordinate with the technical team before adding, deactivating, or deleting a language.

## What the page shows

The table lists each language with the columns **Code** (language code, for example `id`, `en`), **Name**, **Status**, and **Action**. The main language is marked with a **Default** label.

## What does the Default language mean?

- Required fields (\*) in CMS forms are only required in the Default language.
- If a text has not been translated into another language, the website shows the text in the Default language.
- The Default language **cannot** be deactivated or deleted.

## Available actions

| Action | How | Effect |
|---|---|---|
| **Add a language** | Fill in **Code** (2–5 letters, for example `jp`) and **Name** under **Add Language**, then click **Add** | A new language tab appears in every CMS form. The technical team must prepare the website before it can show the new language. |
| **Rename** | Click the edit icon, change **Language Name**, then click **Save** | Only changes the displayed name |
| **Deactivate / activate** | Click the **Active / Inactive** label | Inactive languages are hidden from CMS forms |
| **Make default** | Click the **Set as Default** icon | Changes the main website language |
| **Delete** | Click the 🗑️ icon | **All translations** in that language are deleted too |

> **Warning:** Deleting a language **permanently deletes all text** ever entered in that language in every menu (news, projects, profile, and more). This **cannot be undone**. If you only want to hide it for a while, use **Inactive**.
