The **Menu** menu manages the **navigation menu** at the top of the website: the row of links such as *Beranda* (Home), *Tentang Kami* (About Us), *Proyek* (Projects), *Berita* (News), and *Kontak* (Contact).

Open menu: [Menu](cms:admin.menu.index)

## The menu list page

| Column | Description |
|---|---|
| **Name** | The menu name shown on the website (default language) |
| **Slug** | A unique code created automatically. You can ignore it. |
| **Url** | Where the menu link leads |
| **Order** | Order from left to right (smallest number on the far left) |
| **Status** | Active = shown, Inactive = hidden |

## Adding a menu item

1. Click **Add Menu**.
2. Under **Select Website Page**, choose the target page:
   - 🏠 **Home** ( / )
   - 👥 **Stakeholders** ( /stakeholders )
   - 🎬 **Projects** ( /project )
   - 📰 **Articles & News** ( /news )
   - 🏛️ **About Us** ( /about )
   - 📞 **Contact Us** ( /contact )
   - 🔒 **Privacy Policy** ( /privacy-policy )
   - 📜 **Terms & Conditions** ( /terms-conditions )
   - 🔗 **Custom Link / External URL…**: for any other address
3. If you choose a website page, the **URL Link Data** field is filled in and locked automatically. If you choose **Custom Link**, type the address yourself:
   - A page on the BPI website: start with a slash, for example `/news`.
   - Another website: type the full address, for example `https://festivalfilm.id`.
4. Fill in **Display Order** and tick **Status: Active**.
5. Fill in **Menu Name** in the **ID** tab (for example *Berita*) and the **EN** tab (for example *News*).
6. Click **Save**.

## Reordering or hiding a menu item

- **Order:** click ✏️, change **Display Order**, then click **Update**.
- **Hide:** click the **Active** label until it changes to **Inactive**.

> **Tip:** Keep the number of menu items small, ideally 5–7, so navigation stays tidy, especially on phones. Use short names (1–2 words).

> **Warning:** Make sure **Custom Link** addresses are correct. A menu item pointing to a wrong address shows visitors a "not found" page. After saving, click the menu item on the website to test it.
