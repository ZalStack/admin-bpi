Technical terms used in this guide, and the Indonesian words you will see in the CMS and on the BPI website.

## Technical terms

| Term | Meaning |
|---|---|
| **CMS** | *Content Management System*: an application for managing website content without writing code |
| **Website / Landing page** | The public BPI website that visitors see |
| **Admin Panel** | Another name for this CMS |
| **Role** | An account's access level: Super Admin, Admin, or Editor |
| **Sidebar** | The menu on the left side of the CMS screen |
| **Dashboard** | The summary page shown right after logging in |
| **Section** | A part of a page, for example the "Mitra Kami" (Our Partners) section on the home page |
| **Banner** | The large image with a title at the top of a page |
| **Badge** | A small label, usually above a heading or as a small colored box |
| **Footer** | The very bottom part of the website |
| **Default** | The standard or main setting |
| **Slug** | A short code without spaces (lowercase letters and hyphens) used in web addresses, for example `festival-film` |
| **URL / Link** | A web address, for example `https://bpi.or.id/news` |
| **Shortlink** | A short web address that leads to a longer one |
| **QR Code** | A square pattern that a phone camera can scan to open a web address |
| **Upload** | Sending a file from your computer to the CMS |
| **WebP** | A modern, small image format the website uses so pages load faster |
| **Font Awesome** | The icon set used by the website (codes look like `fa-solid fa-film`) |
| **Rich Text Editor** | A text field with formatting buttons, like in Word |
| **Session** | The period you stay logged in. It ends automatically after a long idle time. |

## Indonesian words in the CMS

The CMS screens are in English, but some technical names and official BPI terms are still Indonesian:

| Indonesian | English | Where you see it |
|---|---|---|
| **judul / deskripsi** | title / description | Error messages, for example `translations.id.judul` |
| **Pimpinan Inti, Majelis Dewan, Bidang, Satgas, Pokja, Komite** | Official BPI unit names | In brackets in the Org. Structure options (see the table below) |
